GEO & Schema.org JSON-LD Preflight Validator

A zero-dependency Python CLI check designed to verify root /llms.txt manifests, HTTP 200 canonical routes, and interconnected @graph JSON-LD entities before production deployment.

Core Checks

  • Verifies /llms.txt availability, HTTP 200 status, and structured Markdown headings.
  • Parses every <script type="application/ld+json"> block and checks persistent @id linkage.
  • Prevents stale .html suffixes or broken internal deep links from shipping to production.
